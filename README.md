# QA — Urban Lunch | Testes Mobile

## Sobre o projeto

Projeto prático de testes funcionais de uma aplicação mobile de pedidos de comida, desenvolvido durante a formação em Quality Assurance na TripleTen.

## Atividades realizadas

- Realização de testes funcionais na aplicação mobile;
- Validação da seleção de restaurantes;
- Verificação da escolha de pratos;
- Validação da confirmação dos pedidos;
- Testes do acompanhamento e da conclusão dos pedidos;
- Identificação e registo de falhas no Jira.

## Ferramentas e conhecimentos

- Quality Assurance (QA)
- Testes Manuais
- Testes Funcionais
- Android Studio Emulator
- Jira
